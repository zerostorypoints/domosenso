# Security reporting

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/zerostorypoints/domosenso/security/advisories/new)
when available. If that option is unavailable, contact ZeroStoryPoints GmbH at
[contact@zerostorypoints.com](mailto:contact@zerostorypoints.com) with a short
summary and request a private channel for reproduction details. Do not send
credentials or real home configurations.

Do not disclose vulnerabilities, access tokens, entity identifiers, network details,
HA snapshots or private photographs in public issues or pull requests. Include the
framework commit, component versions and a sanitized reproduction in private reports.

DomoSenso is an early-stage framework. No fixed response-time or support-window
commitment is offered. Keep a verified backup and your home's configuration in a
separate private repository, and review deployment plans before applying changes.
