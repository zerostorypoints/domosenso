# Ramka na tablecie

Pełnoekranowy dashboard Ramki z fikcyjnej instancji Home Assistant. Rozmiar widoku 1100 × 720 CSS px, skala urządzenia 2×.

Dziesięć roślin, ilustracje i przykładowe historie wilgotności pochodzą z demo. Wykresy klimatu i powietrza pokazują stan świeżej instancji bez zapisanej historii.
