# Website audit — ramka 0.17.0, the guides at its commit

Source: `ramka/0.17.0` at `e83edec` (#272, the version bump of work already on main: #248 and the
P3 commits, #267). The Release workflow's pull request #273 (`release/website-ramka-0.17.0`) did the
mechanical part with `publish_release.py`: the selection, the views' `sourceCommit`, and the devices'
compatibility. This note covers that pull request and three commits added to its branch:

- the guides' `documentationCommit` moves from `b6e14f9` to `e83edec`. The same goes for every
  device record and source asset, which must equal it;
- the gate how-to's step 7;
- the Ramka views' conditions and setup.

Between `b6e14f9` and `e83edec`, the published guide sources that changed are:

- `devices/m5stack-module-cc1101.md` with its enclosure files (#268, #270);
- `docs/tablet-setup.md`, with a new section "Home Assistant on the tablet" (#267).

The section was held back until the Ramka work it describes had a tag. With `ramka/0.17.0` it does.
The exported content was compared with an export at `50d10e4`: apart from the commit, it is
identical.
