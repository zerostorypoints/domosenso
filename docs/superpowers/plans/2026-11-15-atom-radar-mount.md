# Atom radar mount implementation plan

> **For agentic workers:** Use superpowers:executing-plans in the current owned worktree. Steps use checkboxes for tracking.

**Goal:** Deliver a reusable all-printed Atom Lite / LD2410C mount with standing and shelf-clamp bases, verified meshes, previews and a local Bambu project.
**Architecture:** One parametric OpenSCAD source defines a raised open-bottom Atom cradle, braced mast, keyed base interface and yaw head. Printed tapered keys retain base and head; a wedge tightens the shelf clamp. Local printer and measured installation inputs stay outside Git.
**Tech stack:** OpenSCAD, Python standard-library build wrapper, installed 3d-print-designer gate and Bambu exporter.
**Spec:** ../specs/2026-11-15-atom-radar-mount-design.md

## Global constraints

- Atom button up, GPIO plugs down; 27 mm clearance for a 25 mm connector/wire envelope.
- Jumpers are 120 mm end-to-end including both female housings; reserve their lengths and
  check a bent, slack route at all yaw poses. Radar height may decrease to fit the available wire.
- Radar centre 72 mm, overall assembly below 100 mm; PCB vertical, yaw only, nominal travel ±60°.
- Both bases reuse the same tower and head; no metal screws, nuts or inserts.
- Local shelf thickness and printer presets stay outside Git; source exposes ordinary dimensions as parameters.
- No HA/device changes. No print is sent. Physical fit/retention remains unverified until coupon feedback.

## Review focus

- Downward connectors and insertion paths cannot collide with the cradle, base or keeper.
- A button press and cable pull must not dislodge the Atom or overturn the base (physical acceptance).
- Head stop/pivot/key must permit rotation when released and retention when tightened.
- Clamp wedge must fit limited under-shelf engagement and remain removable.
- Print orientation, first-layer islands, walls and overhangs must be checked per part.
